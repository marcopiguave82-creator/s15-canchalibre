# CanchaLibre

## Descripción

CanchaLibre es un sistema desarrollado para facilitar la reserva de canchas deportivas dentro del campus universitario.

El sistema permite que los estudiantes consulten los horarios disponibles, reserven una cancha y cancelen una reserva cuando sea necesario. Además, el administrador deportivo puede gestionar la disponibilidad de las canchas.
